# Personal Finance & Expense Analytics Dashboard

A fast, local-first personal finance dashboard that parses bank CSV statements, auto-categorizes spending, and visualizes financial health—processed 100% locally in your browser memory.

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev


```
